# 扫描详情页进度卡片压缩改造：单行进度条 + 弹层详情

## 问题

`ScanProgressOverview`（`packages/web/frontend/src/routes/WorkspaceDetail/ScanProgressOverview.tsx`）在扫描详情页全 tab 常驻 sticky 渲染，**无条件平铺当前 phase 的全部子步骤**（pre-recon 阶段 8 行）+ 每个运行中 Agent 一行，卡片高度 ~300px。logs/live tab 是定高 flex 布局（`h-[calc(100dvh-5.5rem)]`），卡片直接吃掉日志查看区大半高度。

## 方案（已确认：单行进度条 + Popover 弹层）

常驻态压缩为恒定一行（~44px），详情按需弹出，浮层悬浮不挤压布局。

### 1. 重写 `ScanProgressOverview.tsx` 渲染（核心改动）

**保留不动**：`resolveActiveEventsUrl`、SSE hook、`dashboardReducer` fold、props 接口（`ScanDetail` 无需改动）、`STATUS_MAP` 连接态徽章。

**新的单行布局**（`flex items-center gap-3 min-w-0`，卡片 padding 收紧为 p-2.5）：

```
[phase 名 truncate] [分段进度条 flex-1] [2/8 · Agent 1/2 · ✗N] [⟳agent芯片 ×2 +N] [●已连接] [▾]
```

- **分段进度条（替代 8 行列表）**：每个 unit 一段，`h-1.5 flex-1 rounded-full`，颜色按状态：done→`bg-green`、running→`bg-cyan`（加 `animate-pulse`）、failed→`bg-red`、pending→`bg-muted`。每段包现有 `Tooltip`（复用 `ReposTab.tsx:212` 的 `TooltipProvider` 包裹模式），内容 `{unit} · {intent}`。段上加 `data-status` 供测试断言。
- **计数**：保留现有 `进度 X/Y · Agent N/M` 文案；新增失败可见性——`failed > 0` 时追加红色 `✗N`。
- **运行中 Agent 芯片**：`⟳ name t{turn}` 小芯片（`supernova-spinner` + mono xs + border rounded），Tooltip 显示 `last_action_detail ?? last_action`；最多显示 2 个，超出折叠为 `+N`（title 列全部名字）；容器 `min-w-0 truncate` 防长工具名撑爆。
- **连接徽章**：现状保留。
- **ChevronDown 触发器**：ghost 图标按钮（lucide `ChevronDown`），aria-label 走新 i18n key。

**Popover 详情**（`@/components/ui/popover`，`align="end"`，宽 `w-80`）：
- 头部：phase 名 + 计数。
- 步骤列表：**逐字保留现有行渲染**（✓/○/✗/· + unit 名 + intent）。
- 分隔线后：运行中 Agent 详情（spinner + 名 + t{turn} + last_action_detail，允许换行 `break-all`）。

### 2. i18n：`locales/zh.json` / `en.json`

新增 `workspaceDetail.live.progressDetails`：zh「进度详情」/ en「Progress details」（chevron 的 aria-label + title）。

### 3. 更新测试 `ScanProgressOverview.test.tsx`

- `resolveActiveEventsUrl` 纯函数测试不动。
- 「渲染 phase_units 步级列表」→ 改为：先断言进度条分段存在（`data-testid="progress-strip"` 段数），再点 chevron 打开 Popover 后断言步骤名/ intent 可见。
- 「渲染正在跑的 Agent」→ 芯片仍渲染 agent 名，断言基本保留；Agent 详情（工具调用）在 Popover 内补断言。
- 新增：failed 步骤 → `✗1` 红色计数出现 + 对应段 `data-status="failed"`。
