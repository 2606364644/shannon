# 「产物」tab 重设计：左树右预览（master-detail）

## 背景与问题

产物页（`DeliverablesTab.tsx`）当前是固定两栏 `[漏洞聚合 1fr | 文件树+预览 360px]`：点任何文件（含完整 Markdown 报告）都渲染在右侧树的**下方窄列**里，主区域永远被漏洞列表占据；组合/非组合用两套割裂的文件浏览器（`FileTree` emoji 树 vs `CombinedBuckets` 扁平列表）；`big_json` 是"去磁盘看"死胡同、`kind:"other"` 渲染空 `<pre>`；预览用裸 fetch 不走 SWR，切换文件闪烁重拉。

用户已确认：**左树右预览布局**（默认右侧=漏洞聚合，点文件后切换为全宽预览），**范围只做产物 tab**，其他 tab 不动。

## 目标布局

```
┌──────────┬─────────────────────────────────────────────┐
│ ◈ 漏洞聚合·12 │  ◀ 返回漏洞列表   whitebox/injection_…md │
│ ▾ 白盒    │  size · kind · [复制]                        │
│   📄 …md  │ ─────────────────────────────────────────── │
│   ▾ 注入  │  md → 全宽 MarkdownView                      │
│ ▸ 黑盒    │  exploitation_queue → VulnCard 结构化列表    │
│ ▸ 融合    │  llm/gn/other_json → 格式化 JSON + 复制      │
│           │  big_json → 提示 +「仍要加载」按需拉取(截断)  │
│ ~280px    │  other → 诚实「不支持预览」空态               │
│ 独立滚动   │  未选文件 → 漏洞聚合卡片列表（默认态）        │
└──────────┴─────────────────────────────────────────────┘
```

## 改动文件

### 1. `src/components/FileTree.tsx` — 演进为统一文件浏览器
- emoji/文本字形（📂📄▾▸）换成 lucide 图标：`ChevronDown`/`ChevronRight`、`Folder`、`FileText`（md）、`FileJson`（json 类）、`File`（other）。
- 新增可选 prop `selectedPath?: string | null`：选中文件高亮（`bg-accent text-accent-foreground`）。
- 顶层 track 目录（`whitebox`/`blackbox`/`combined`）显示本地化友好名（白盒/黑盒/融合），其余目录显示原名——组合扫描的三桶语义自然融入一棵树。
- 保留 `empty`/`large` 尾注。API 兼容（`files` + `onSelect` 不变）。

### 2. 新建 `src/routes/WorkspaceDetail/FileStage.tsx` — 文件预览舞台
- **头部**：返回按钮（`← 漏洞聚合`）+ 等宽文件名（含 track 前缀路径）+ 可读 size + kind Badge + `CopyButton`（文本内容可复制时）。
- **内容按 kind 分派**：
  - `md` → 全宽 `MarkdownView`（复用报告引擎）。
  - `exploitation_queue` → `JSON.parse` 后取 `{vulnerabilities:[]}` 渲染 `VulnCard` 列表（复用现组件）；解析失败回退原始文本。
  - `llm_queue`/`gitnexus_queue`/`other_json` → 格式化 JSON `<pre>` + CopyButton。
  - `empty_json` → 保留现有"无数据（常态空）"空态。
  - `big_json` → 保留"文件过大"提示 + 字节数，新增**「仍要加载」按钮**按需拉取，展示截断前 256KB 并提示已截断（消除死胡同，默认仍零 fetch）。
  - `other` → 诚实的"该类型不支持预览"空态（修复永远空的 `<pre>`）。
- 数据层换 `useApiText`（SWR）：来回切换文件秒显缓存、不再闪烁；`?path=` 请求语义不变。

### 3. `src/routes/WorkspaceDetail/DeliverablesTab.tsx` — 布局重写
- 外层改 `grid grid-cols-1 lg:grid-cols-[280px_minmax(0,1fr)] gap-5`（窄屏堆叠，`minmax(0,1fr)` 防长代码行撑爆）。
- **左列**（`max-h-[calc(100vh-220px)] overflow-auto`，同现有右列做法）：置顶"漏洞聚合 · N"入口（lucide `ShieldAlert` 图标，点击清空文件选中）+ 统一 `FileTree`。
- **右列（舞台）**：未选文件 → 现有聚合视图（标题 + injection badge + Empty + VulnCard 堆叠，整体平移过来）；选中文件 → `FileStage`。
- 删除 `CombinedBuckets`（树按 track 前缀自然分组）与内嵌 `FilePreview`/`MarkdownViewLazy`。
- 保持现有行为：SWR summary 拉取、`selectedRun` → `blackboxRunDeliverablesPath`、path 变化重置选中、三态早返回（ErrorState/Skeleton/data）。

### 4. i18n（`src/locales/en.json` + `zh.json`）
新增 key（两语言）：返回漏洞列表、文件大小、不支持预览、仍要加载、已截断提示、复制内容、聚合入口名。复用现有 `workspaceDetail.deliverables.*` key 不删（bigJson/emptyJson 文案沿用）。

### 5. 测试更新
- `DeliverablesTab.test.tsx`：现有 12 个用例多为文本级断言（SSRF-01、漏洞聚合 · 1、点文件触发 `?path=`、big_json 不发请求等），预计大部分存活；需要新增：默认态=聚合列表在舞台、选文件后出现文件名头部+返回按钮、`exploitation_queue` 结构化渲染 VulnCard、`other` kind 无空 `<pre>` 且显示不支持预览、big_json「仍要加载」按需 fetch、选中文件高亮。
- `FileTree.test.tsx`：emoji 断言改 lucide（按 role/aria 或文本）、新增 selectedPath 高亮 + track 目录友好名用例。
- 若有对 `combined-bucket-*` testid 的断言（仅 DeliverablesTab 自身），改为树形三组断言。

- 后端 API 改动（无 range 支持，故 big_json 用前端截断方案）
- VulnCard 与 MarkdownView 内漏洞卡的双实现合并
