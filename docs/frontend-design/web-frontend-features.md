# Supernova Web 控制台 — 页面设计与功能说明

> 用途:面向**未接触过本仓库代码**的前端开发,说明当前 Web 控制台「长什么样、能做什么、有哪些特性与功能」。
> 视角:产品 / 设计 / 交互,不含代码实现细节(文件路径、接口、数据字段等内部信息一律略去)。
> 维护:2026-08-13。

---

## 这是什么
一个**安全审计平台**的 Web 控制台。用户在这里管理工作区和代码仓库、发起扫描、实时观察扫描过程、查看结构化的漏洞报告和产物,并维护认证登录档案、域名映射档案、用户和系统配置。

## 整体设计风格
- **纯顶栏布局,没有左侧侧边栏**,内容区居中、流式排列。
- **珊瑚色(coral)暖纸风**:主色是温暖的橙红,背景低饱和,卡片用细边框 + 柔和阴影,整体克制不花哨。
- **支持深色 / 浅色 / 跟随系统**三种主题,**中英文双语**随时切换。
- **卡片化**为主:扫描、漏洞、档案都以卡片呈现;状态用**带图标的彩色徽章**统一表达(进行中 = 青色、完成 = 绿色、失败 = 红色、中断 = 黄色)。
- 加载、空数据、出错都有**统一的占位样式**(转圈、空态插画、可重试的错误块)。

## 导航与信息架构
顶栏固定 4 个入口:**概览 / 工作区 / 扫描 / 设置**(右侧还有语言、主题切换和用户菜单)。

核心是**两层结构**:
- **工作区(workspace)** = 容器,装着多个仓库和多次扫描;
- **扫描(scan)** = 一次具体任务,归属于某个工作区。

点「工作区」会**智能跳转**:优先进你置顶的工作区,否则进最近活跃的,都没有就回总览。

## 三类扫描 + 状态
发起扫描时选三种类型:
- **白盒**:离线源码审计,选一个工作区里已下载的代码仓库。
- **黑盒**:针对一个在线目标 URL 做「利用验证」,且**必须复用一次已有的白盒扫描结果**(不单独跑一遍代码分析)。
- **关联**:跨多个仓库做微服务间的关联分析,用一段 YAML 配置描述。

扫描有一套状态流转:**进行中 → 完成 / 失败 / 被杀 / 崩溃**,中途异常中断的可以**「恢复」继续跑**。

## 各页面功能

### ① 总览(首页)
跨所有工作区的扫描大盘。顶部 4 个汇总数字(运行中数量、今日完成、累计发现漏洞、累计花费),下面是「运行中」的扫描卡片网格,再下面是带**四维筛选**(关键词、状态、类型、时间范围)的扫描列表表格。管理员可以直接在这里取消正在跑的扫描。

### ② 新建扫描
顶部三个标签页切换扫描类型。
- 白盒:简洁单栏,先选工作区、再选该工作区里已下载的仓库。
- 黑盒:双栏布局。填目标 URL、选工作区和要复用的白盒结果;认证是一块**可折叠区域**,点「配置登录」展开,展开后可选「临时填写」或「复用已存档案」两种方式,支持**多角色账号**(比如同时配管理员、普通用户多套凭据做对比)。
- 关联:一个 YAML 编辑器,实时校验语法。

支持「重跑」——把某次扫描的配置原样带回来预填,改完再提交。

### ③ 扫描详情(5 个视图)
进入某次扫描后,顶部显示任务名、状态、类型,下面 5 个切换页签:
- **概览**:成本 / 耗时 / 智能体数量的三大数字,**阶段瀑布图**(按各阶段耗时占比画色块条),以及每个智能体的耗时台账(含重试次数)。
- **报告**:把后端生成的 Markdown 报告渲染成漂亮的「安全报告」——顶部威胁概览条(按严重度 Critical / High / Medium / Low 堆叠)、最高风险发现高亮卡、按漏洞类型汇总的卡片、**左侧固定目录**可点击跳转并随滚动高亮当前章节、漏洞卡片网格(可折叠,严重度配色,公网可达的红框高亮)。
- **产物**:左边是聚合的漏洞卡片列表,右边是文件树,点开任意产物文件能预览(Markdown 渲染、JSON / 队列文件原文、超大文件不卡死)。
- **日志**:扫描日志文件浏览器。左边选文件、右边看内容;JSON 格式的日志逐行解析成**带颜色和时间的事件行**,行数特别多时自动虚拟滚动,时间从服务端时区转成本地。
- **实时**:扫描进行时的**实时控制台**(这是唯一实时推送的页面)。显示当前阶段、脉冲指示、已耗时、花费、正在跑的智能体,以及一条**实时滚动的事件日志流**(阶段 / 步骤 / 智能体 / 工具调用 / 错误,每种事件有不同图标和颜色)。结束时给出横幅提示:成功 → 给「查看报告」入口,失败 → 展示错误尾部。

### ④ 扫描列表(工作区内)
这个工作区下所有扫描的卡片列表,每行展示任务名、状态徽章、类型、漏洞数、花费、时间,以及一排操作:**查看 / 恢复 / 重跑 / 取消 / 删除**(各有按钮和确认弹窗)。

### ⑤ 仓库管理(工作区内)
工作区里代码仓库的管理。顶部是总数 / 总大小 / 就绪数 / 克隆中数的汇总条,下面按分组展示(可折叠),支持搜索和多选批量删除。每个仓库显示来源地址、分支、大小、状态;正在克隆 / 拉取的会显示**实时进度**。管理员还能「批量关联」磁盘上一个目录里的所有 git 仓库。

### ⑥ 认证档案(黑盒登录配置库)
把黑盒要用的登录信息存成可复用的档案(支持多角色),省得每次手填。
- **列表页**:档案的增删改;有一类**系统级全局只读档案**(只能「复制一份到自己工作区」再改,不能直接编辑)。每条凭据显示成小标签(带状态色点),点击可**新开标签页**看它的登录测试过程。
- **批量测试页**:对一个档案**多选角色,串行逐个验证每个角色到底能不能登录成功**(不是越权对比),跑的时候每个角色实时显示进度。
- **过程实时页**:某条凭据的登录测试,既有**实时步骤条 + 日志流**,也能回看最近一次测试的完整记录;刷新页面能自动恢复中断的测试。

### ⑦ HOST 档案(域名 → IP 映射)
和认证档案同款范式。维护「域名 → IP」的映射表,黑盒扫描时用来覆盖 DNS / 走代理。可以手动填,也可以贴一个 URL 把 `/etc/hosts` 风格的文本拉进来自动解析填充。同样有系统级只读档案可复制。

### ⑧ 设置 / 用户 / 登录
- **设置页**:改平台品牌名(管理员,实时预览)、切主题、改自己密码、查看系统状态(用的哪个 AI 引擎、浏览器引擎、调度服务是否连通、git 是否就绪、版本号)。首次登录的默认账号会被强制提示改密码。
- **用户管理**(仅管理员):用户表格,能创建用户、改角色、重置密码、删除,还能展开看每个用户属于哪些工作区;**不能操作自己**(防误删)。
- **工作区设置**:编辑该工作区的环境配置(工作区管理员可写、普通成员只读,凭据以掩码显示)。
- **登录页**:用户名 + 密码,会话过期会提示并跳回。

## 几个值得注意的功能特性
1. **实时执行可视化**:扫描在跑的时候,实时页用推送方式展示阶段进度、智能体行为、逐条事件日志,像看一个带时间轴的控制台,不用手动刷新。
2. **结构化安全报告**:不是丢一坨 Markdown 文本,而是解析成带目录、威胁概览、严重度配色、可折叠漏洞卡、攻击链单独成章的「成品报告」。
3. **认证登录测试体系**:不只能存登录配置,还能**真的去测一遍**多角色能不能登录,并实时展示登录过程、失败原因。
4. **两级权限**:全局管理员 / 普通用户,工作区内管理员 / 成员;不同角色看到的入口和能做的操作不同(比如建工作区、改品牌名、关联磁盘仓库都限管理员)。
5. **系统级只读档案 + 复制到工作区**:公共配置(如一套标准登录档案、域名映射)由系统下发,各工作区复制一份后自行修改,互不污染。
