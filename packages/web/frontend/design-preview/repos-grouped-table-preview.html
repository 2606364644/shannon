设计要点
  • signature = 结构即信息：分组行不是装饰，是一条 colspan=6 的 section heading——折叠三角 + 组名（Mono）+ tabular 计数 + 右侧整组全选。比现状的 Card 头更紧凑，分组边界依然清晰。
  • sticky 列头：thead th { position: sticky; top: 0 }，16 行滚动时列名常驻——这是现状「多表各自带列头」做不到的核心收益。分组行同样 sticky（紧跟列头下），分组多时不丢失。
  • 全局列宽对齐：单表 table-layout: fixed + colgroup，所有分组共用一套列宽，跨组扫读不再错位。
  • 状态语义：就绪 green / 失败 red / 未完成 yellow / 克隆中 cyan（含进度条）——取自 STATE_BADGE + stateAccent 左侧色条，异常态一眼定位。
  • 批量操作：行勾选 → 顶部批量条浮现（已选 N + 删除 + 清除）；分组行整组全选自然落在同一张表内。
  • 落地成本：groupRepos() 照用，只是渲染从「多 Card」改成「单 Table 内插 <tr class="grp">」；现有交互（折叠/全选/批量/CloneProgress）逻辑几乎不变。
