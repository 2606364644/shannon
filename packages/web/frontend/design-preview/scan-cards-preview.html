设计要点
  • signature = 攻击方向镜像：白盒卡的标记是「多个源点 → 单 sink」（源码侧 taint 汇聚到 sink，向右）；黑盒是「外侧打击 → 目标靶心」（向左）。两张卡的流向在中缝相会——inside-out vs outside-in 不是文案，是图形本身在表达。
  • 姿式卡片取代 tab：白 / 黑不再埋在一条 tab 里，而是两张常驻卡片，选中 = coral 描边 + 柔光 + 右上勾。选择有分量，且随时一键切换。
  • 统一骨架消跳变：下方配置区四段（主要输入 / 上下文 / 认证 / 进阶）对所有姿式相同，只换字段内容——白盒填仓库、黑盒填目标 URL，但宽度、间距、段落节奏一致，切姿式不再布局抖动。
  • 去掉模板化的 ①②③ 步骤编号：原白盒的数字圆点是「假序列」装饰；重构用语义段落标题（coral 竖条 eyebrow）代替。
  • 关联扫描降为三级：correlation 不再占一个 tab，改为姿式区下方一条虚线 affordance（默认关），主路径更聚焦。
  • 品牌一致：coral 仅作选中 / 强调；暖纸张低饱和、hairline + 柔阴影浮起；IBM Plex Serif 用于标题、Mono 用于 eyebrow / 数据——全部取自现有 tokens.css，零新色。
