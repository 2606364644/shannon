安全评估报告

本次评估对 OWASP NodeGoat v1.3.0 的全部网络可达攻击面完成系统性白盒审计，共确认 36 个漏洞（injection 4、xss 13、auth 10、authz 7、ssrf 2），覆盖 OWASP Top 10 中的注入、跨站脚本、失效的认证、失效的访问控制与 SSRF 五大类。

13XSS · H~L

7Authz · High
2SSRF · C~H

根因概述：该应用把几乎所有防御控制（helmet、csurf、bcrypt-nodejs、HTTPS、cookie 标志、Swig autoescape）都以注释掉的 // Fix for A? 代码块形式保留——依赖已声明但未启用。部署形态下几乎不携带任何运行时防御。

执行摘要 · 最高风险发现

  1. INJ-VULN-01/02/03 服务端 RCE：POST /contributions 的 preTax/afterTax/roth 直达 eval()，可执行系统命令；仅需任一登录态。pre-auth 可达
  2. SSRF-VULN-01 完整响应 SSRF：GET /research 将 req.query.url 拼接后出站并回写完整响应体，可命中 AWS IMDS / loopback / 内网。公网
  3. AUTH-VULN-08 管理员账户接管：硬编码默认凭据 admin/Admin_123 每次容器启动重灌。
  4. XSS-VULN-04 经公开注册对 admin 的存储型 XSS：admin 查看 /benefits 即触发；叠加 csurf 全局禁用，可链 XSS→CSRF。
  5. AUTHZ-VULN-01/03/06 横向/纵向越权：/allocations/:userId 与 POST /benefits 的 userId 取自 params/body 而非 session。

按漏洞类型汇总

Injection · Critical ~ High · 4

3 条 SSJS/命令注入（RCE）—— POST /contributions 的 preTax/afterTax/roth 各自直达独立的 eval()；1 条 NoSQL $where 注入。全部仅需 isLoggedIn，置信度 high。

XSS · High ~ Medium · 13

3 个 pre-auth 反射型 XSS（/login、/signup 属性回显）；多个存储型，首要为经公开注册对 admin 投毒。全局根因为 Swig autoescape:false。

Auth · High ~ Medium · 10 (8H/2M)

会话生命周期失控 + 凭据策略全面失守 + 缺失 abuse 防御。其中 8 条 High、2 条 Medium。
